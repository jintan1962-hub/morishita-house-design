# 変更点マップ

| 変えたいこと | 直すファイル | 直したあとに確認する画面 |
| :--- | :--- | :--- |
| 電話番号・営業時間を変える | src/config/company.ts | トップpage・ヘッダー・物件詳細・送信メール |
| 会社名・住所を変える | src/config/company.ts | フッター・送信メール本文の署名 |
| メールの差出人アドレスを変える | src/config/company.ts（MAIL_FROM） | 会員登録完了メール・問い合わせ控えメール |
| ローン金利・借入年数・想定リノベ費用を変える | src/config/loan.ts | 物件詳細の月々返済額・資金計画ページ |
| 権限区分を増やす／変える | src/config/security.ts（ROLE） | 管理画面全体・各サーバーアクション |
| ログイン試行回数・セッション有効期限を変える | src/config/security.ts | ログイン画面 |
| 物件の公開レベルの意味を変える | src/config/security.ts（DISCLOSURE_LEVEL） | 物件一覧・物件詳細 |
| メール送信を止める | Supabase の SystemSetting テーブル（key=MAIL_SENDING_ENABLED を false） | 会員登録・問い合わせ送信 |
| 管理者への通知先を変える | 環境変数 MAIL_ADMIN_ADDRESS | 問い合わせ送信後・会員登録後／/admin/mail-logs |
| メールの文面を変える | src/lib/mailPayload.ts | 会員登録完了メール・問い合わせ控え・管理者宛通知（※変更後は必ず pnpm test を実行） |
| メールが届いたか確認する | （コードではなく）管理画面 /admin/mail-logs | 送信結果の一覧 |
| 会員一覧に表示する項目を増やす | src/app/(admin)/admin/users/page.tsx | 管理画面の会員管理 |
| ローン計算式そのものを変える | src/lib/loan.ts | 物件詳細・資金計画（※変更後は必ず pnpm test を実行） |
| 掲載対象のエリアを増やす／減らす | src/config/property.ts（AREAS） | 物件一覧・CSV取込（対象外は取込が中止される） |
| 物件種別を増やす／変える | src/config/property.ts（PROPERTY_TYPE） | CSV取込・物件一覧 |
| CSVの読み取り方を変える（文字コード・区切り） | src/lib/csv.ts | 管理画面の一括入力（※変更後は必ず pnpm test を実行） |

このマップに2ファイル以上書かれている行は D-19 違反の候補として扱う。マップは散らばりを許すための地図ではなく、散らばりを見つけるための道具である。
