# 本番環境の作り方（Supabase / Vercel / GitHub）

モリシタハウス版の本番環境をゼロから作る手順。**RENOEL版（used-housing-site）とは
リポジトリ・DB・ドメインを一切共有しない**ことが前提。

> **なぜ分けるのか**
> このプロジェクトは used-housing-site を複製して作った。複製直後は
> git remote も `.env` も**本家の本番を指したまま**で、`git push` すれば
> 8/19 に稼働した RENOEL の本番サイトを上書きし、`prisma migrate deploy` すれば
> RENOEL の本番DB（実物件と会員の個人情報が入っている）に当たる状態だった。
> 「同じ仕組みを使う」ことと「同じ環境を使う」ことは別である。

## STEP 1. Supabase（未着手）

### 1-1. プロジェクトを作る

新規プロジェクトを作成する。**既存プロジェクトの別スキーマにしない**
（接続文字列が共通になり、片方の事故がもう片方に波及するため）。

| 項目 | 推奨値 |
| :--- | :--- |
| Organization | 既存でよい |
| Project name | `morishita-used-housing` など、RENOEL と取り違えない名前 |
| Region | **Northeast Asia (Tokyo)** — `ap-northeast-1` |
| Database Password | 自動生成でよい。**この画面でしか全文を見られないので控える** |

### 1-2. 接続文字列を控える

Project Settings → Database → Connection string から2種類を取る。

| 用途 | どれか | ポート |
| :--- | :--- | ---: |
| `DATABASE_URL` | **Transaction pooler**（`?pgbouncer=true` が付く） | 6543 |
| `DIRECT_URL` | **Direct connection** | 5432 |

`DIRECT_URL` はマイグレーション用。pooler 経由だとマイグレーションが失敗する。

### 1-3. Storage のバケットを作る

Storage → New bucket

| 項目 | 値 |
| :--- | :--- |
| Name | `property-images`（`SUPABASE_STORAGE_BUCKET` を設定しない場合の既定値） |
| Public bucket | **ON** |

物件写真は誰でも見える前提で、画面が `<img src>` に公開URLをそのまま入れている。
Private にすると署名URLの発行が要るようになり、コードの変更が必要（現状は未対応）。

### 1-4. API キーを控える

Project Settings → API から2つ。

| 用途 | どれか |
| :--- | :--- |
| `SUPABASE_URL` | **Project URL**（`https://xxxx.supabase.co`） |
| `SUPABASE_SERVICE_ROLE_KEY` | **service_role** キー（anon キーではない） |

> `SUPABASE_URL` はダッシュボードのURL（`supabase.com/dashboard/...`）でも
> DBのホスト名（`db.xxxx.supabase.co`）でもない。取り違えは
> `src/lib/storage.ts` の `describeConfigProblem()` が起動時に検知して文言で教える。

> `SUPABASE_SERVICE_ROLE_KEY` に `NEXT_PUBLIC_` を**付けないこと**。
> 付けるとブラウザへ配信され、DBを全操作できる鍵が公開される。

## STEP 2. Vercel（未着手）

### 2-1. プロジェクトを作る

Add New → Project → 上記の GitHub リポジトリを Import。

| 項目 | 値 |
| :--- | :--- |
| Framework Preset | Next.js（自動検出される） |
| Root Directory | `./` |
| Build Command | 既定のまま（`pnpm build`） |
| Node.js Version | 20 以上 |

**初回のビルドは環境変数を入れる前に走らせない。** 先に 2-2 を済ませる。

### 2-2. 環境変数を登録する

Settings → Environment Variables。Production / Preview の両方に入れる。

#### 必須（これが無いと動かない）

| キー | 出どころ |
| :--- | :--- |
| `DATABASE_URL` | STEP 1-2 の Transaction pooler |
| `DIRECT_URL` | STEP 1-2 の Direct connection |
| `NEXTAUTH_SECRET` | `openssl rand -base64 32` で生成。**ローカルと別の値にする** |
| `NEXTAUTH_URL` | 本番のURL（例 `https://morishita-used-housing.vercel.app`） |
| `NEXT_PUBLIC_SITE_ORIGIN` | 同上。メール本文のリンクに使われる |

> `NEXTAUTH_SECRET` にフォールバック値をコードへ置かない（過去に事故あり）。
> 未設定ならアプリは起動しない。それでよい。

#### 物件画像（管理画面から写真を上げるなら必須）

| キー | 出どころ |
| :--- | :--- |
| `SUPABASE_URL` | STEP 1-4 の Project URL |
| `SUPABASE_SERVICE_ROLE_KEY` | STEP 1-4 の service_role キー |
| `SUPABASE_STORAGE_BUCKET` | `property-images`（既定と同じなら省略可） |

#### メール（会員登録・問い合わせの自動返信）

| キー | 出どころ |
| :--- | :--- |
| `RESEND_API_KEY` | resend.com のAPIキー（`re_` で始まる） |
| `MAIL_FROM_ADDRESS` | Resend で認証済みドメインのアドレス |
| `MAIL_ADMIN_ADDRESS` | 問い合わせ・入会の通知先 |

**未設定でもサイトは動く。**ただし送信は必ず失敗として `MailLog` に記録される
（黙って届かない状態にはならない）。ドメイン認証前の動作確認だけなら
`MAIL_FROM_ADDRESS` に `onboarding@resend.dev` を使える。

#### 計測タグ（任意）

`NEXT_PUBLIC_GA4_ID` / `NEXT_PUBLIC_GOOGLE_ADS_ID` /
`NEXT_PUBLIC_CLARITY_ID` / `NEXT_PUBLIC_META_PIXEL_ID`

未設定ならタグは1本も出力されない。

> **他社（大井建設工業／RENOEL）のIDを入れないこと。** 複製元には直書きされており、
> そのままだとモリシタハウスの訪問者データが他社の解析アカウントへ送られる。

## STEP 3. スキーマを本番DBへ流す

環境変数の登録が済んだら、AI が実行する（D-14。実行前に確認を取る）。

```bash
prisma migrate deploy
```

適用されるマイグレーションは8件（`prisma/migrations/`）。
**この時点では本番DBは空。**会員も物件も0件で、管理者もいない。

---

## STEP 4. 管理者アカウントを作る

`role` の付与は**DB直接操作のみ**（画面からは昇格できない仕様）。

1. サイトの `/member` から通常どおり会員登録する
2. Supabase の Table Editor で `User` テーブルを開き、
   そのメールアドレスの行の `role` を `USER` → `ADMIN` に変更する
3. 一度ログアウトして入り直す（セッションに role が入っているため）

> `pnpm seed:dev` は本番に使えない。ローカル以外の接続先を検知すると中止する作りになっている。

## STEP 5. 公開前の確認

| 確認項目 | 見るところ |
| :--- | :--- |
| 未ログインで会員限定物件の価格・所在地が出ていないこと | ページのソースを開いて検索する |
| 会員登録の自動返信が届くこと | `/admin/mail-logs` に「失敗」が出ていないか |
| 物件画像がアップロードできること | `/admin/properties` から1枚上げてみる |
| 計測タグが意図したものだけ出ていること | ページのソースで `gtag` / `fbq` を検索 |
| 免許番号が表示されていること | フッター・会社概要（宅建業法の表示） |
