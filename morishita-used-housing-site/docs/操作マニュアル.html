1. はじめに

このサイトは2つの顔を持っています

/ 公開サイト

どなたでも見られる物件情報、資金計画、会社案内。会員登録とログインの入口もここにあります。

/admin 管理画面

物件・会員・お問い合わせを扱う社内用の画面。管理者権限を持つアカウントでログインしたときだけ開けます。

管理者としてログインする

  1. 会員登録をする公開サイトの「無料会員登録」から、ふだんお使いのメールアドレスで登録します。この時点ではまだ一般の会員です。
  2. 管理者に切り替えるデータベース（Supabase）の User テーブルで、そのメールアドレスの行の role を USER から ADMIN に変更します。画面からは管理者になれません。
  3. 一度ログアウトして入り直す権限はログインしたときに読み込まれるため、入り直さないと管理画面が開きません。
  4. /admin を開く以降はログインしたまま管理画面を使えます。
セキュリティの決まり

パスワードを続けて5回まちがえると15分間ログインできなくなります。ログインした状態は8時間で切れ、その後は入り直しが必要です。管理者権限をデータベースからしか付けられないのは、画面の操作ミスや乗っ取りで権限が広がらないようにするためです。

2. 管理者ダッシュボード

/admin を開くと最初に出る画面です。表示されている数字はすべてその時点のデータベースの実測値で、サンプルや概算ではありません。

いちばん上「対応が必要なこと」

放っておくとお客様に不利益が出るものだけを出しています。ここが「いま対応が必要なものはありません」なら、急ぎの用件はありません。

出るもの意味押すとどこへ
未対応のお問い合わせが○件まだ「対応済」にしていないお問い合わせお問い合わせ管理
送信に失敗したメールが○件相手に自動返信が届いていない状態メール送信ログ
画像が1枚もない物件が○件写真のない物件が公開されている状態物件管理

4つの数字

数字内訳として出るもの
登録会員数管理者を除いた人数。うち有効な会員と店舗会員の数
掲載物件数一般公開と会員限定の内訳

下段には「最近の登録会員」と「最近更新した物件」が並び、そのままそれぞれの一覧へ進めます。

3. 物件を掲載する

/admin/properties。掲載中の物件の一覧です。上の検索窓では物件名・管理番号・所在地・間取り・エリア名をまとめて探せ、「公開レベル」で一般公開と会員限定を分けて表示できます。

先に知っておいてください

物件の新規登録は、いまのところCSVの一括入力だけです。画面に「物件を1件つくる」ボタンはありません（押しても何も起きないボタンを置かないための判断です）。すでにある物件の内容を直す・写真を足すのは画面からできます。

3-1. CSVで一括登録する

「一括入力 (CSV)」を押すと取り込みの画面が開きます。数える→見せる→承認を取る→書き込むの順に進み、確認を通るまで1件も書き込まれません。

  1. CSVファイルを選ぶExcelからそのままCSV保存したもの（Shift-JIS）でも、UTF-8でも読めます。判定した文字コードは次の画面に表示されます。
  2. 照合結果を確認する「読み取った行数／新規登録／上書き／変更なし」の件数が出ます。ここの数字が想定と違うときは実行しないでください。表の物件名が化けていないかも、この画面で見ます。
  3. 取り込む行を選ぶ最初は全行にチェックが入っています。外した行は取り込まれません。1行ずつ「新規／変更あり／変更なし」と変更箇所が出ます。
  4. 「○件の取り込みを実行」を押す確認のダイアログがもう一度、件数と上書き件数を出します。ここで初めて書き込みます。
  5. 控え番号を控える完了画面に「上書き前データの控え番号：#○○」が出ます。戻したいときに使う番号です。実行のたびに控えは自動で取られます。
上書きの仕組み

同じ物件管理番号（objMngNo）の行を再度取り込むと、その物件が上書きされます。番号を変えれば別物件として増えます。つまり番号の付け方がそのまま更新か新規かを決めます。

一括出力 (CSV)

いま画面に読み込まれている物件を書き出します。出るのは管理番号・物件名・価格・間取り・所在地・公開レベルの6項目だけです。全項目のバックアップではない点にご注意ください。

3-2. CSVの列

1行目が見出し行。列の順番は問いません。見出しの名前が一致しない列は黙って無視されますので、うまく入らない項目があるときは、まず見出しの綴りを疑ってください。値にカンマが入るときは "3LDK（和8・洋12）" のように " で囲みます。

3-3. 写真を入れる

方法1：ファイル名でまとめて入れる

「画像を一括アップロード」から、ファイル名を「物件管理番号_連番.拡張子」にしてまとめて選びます。

ファイル名結果
6991580385_1.jpg管理番号6991580385の物件の1枚目
6991580385_2.jpg同じ物件の2枚目
6991580385.jpg連番を省くと1枚目になる
  • 区切りは _ でも - でもよく、_02 のようなゼロ埋めも使えます。
  • 同じ連番のファイルを入れると、その1枚だけ差し替わります（重複して増えません）。
  • 管理番号がデータベースにないファイルは取り込まず、理由を1件ずつ画面に出します。

方法2：物件ごとに足す

物件の編集画面「物件画像」から追加します。ファイル名は自由で、並び順は自動で最後に付きます。各画像の左上に並び順、右上に削除ボタンが出ます。

制限値
使える形式jpg / jpeg / png / webp
1枚あたり5MB まで
1物件あたり20枚 まで
削除は取り消せません

画像を削除すると、データベースの記録と保管先のファイルの両方が消えます。元に戻せません。差し替えたいだけなら、同じ連番のファイルを入れて上書きしてください。

写真の権利

写真は物件の事実データとは別に、撮影者や元付業者の著作物にあたります。掲載許可の範囲に写真が含まれているかをご確認のうえ掲載してください。

3-4. 1件ずつ直す

一覧の物件名または「編集」から物件の画面へ進みます。上部に会員の閲覧数・問い合わせ件数・最終更新が出て、「サイトで確認」から実際の見え方も開けます。

区分直せる項目
区分公開レベル（一般公開／会員限定）、物件種別、エリア
基本情報物件名、価格、間取り、所在地、物件種目
面積・建物土地面積、建物面積、建物構造、築年、築月、階建/階、駐車場
交通交通（全文）、沿線名、駅名、駅から徒歩
費用・条件権利金、敷金・保証金、維持費等、土地権利、現況、引渡可能時期、取引態様 ほか
マンション／土地固有管理費、修繕積立金、総戸数、所在階、建ぺい率、容積率、用途地域 ほか

物件管理番号だけは画面から変えられません。CSV取り込みで物件を見分ける鍵として使っているためです。

4. 会員を管理する

/admin/users。サイトから登録された会員の一覧です。氏名・メールアドレスで検索でき、会員種別（無料会員／店舗会員）と状態（有効／停止）で絞り込めます。

会員の詳細でできること

  • 氏名・メールアドレス・電話番号・住所・登録日の確認
  • 停止と再開の切り替え — 「この会員を停止する」を押すと確認のうえ状態が変わります。停止した会員は会員限定物件を見られなくなります
  • 活動履歴（最新20件） — ログイン、物件閲覧の記録
「テストデータ作成」は本番で押さない

会員一覧にある「テストデータ作成」は、動作確認用の会員をその場で作るボタンです。お客様の実データが入っている本番では使わないでください。作った会員は削除（一覧から見えなくする論理削除）で片づけられますが、混ざると数字が狂います。

5. お問い合わせに対応する

/admin/inquiries。受信日時・お名前・連絡先・対象物件・内容が一覧で並びます。会員からのお問い合わせには「会員」の印が付きます。

  1. 内容を開く本文をクリックすると詳細が開きます。Esc で閉じられます。
  2. お客様へ連絡する電話またはメールソフトから、いつもどおりご連絡ください。この画面から返信メールは送れません。
  3. 「対応済」に切り替える状態のバッジを押すと切り替わり、完了日時が記録されます。押し間違えたら、もう一度押すと「未対応」に戻ります。

対象物件が削除済みの場合は「この物件は削除されています」と表示され、管理番号だけが残ります。物件と結び付かない一般のお問い合わせは「一般のお問い合わせ」と出ます。

6. メールの送信結果を見る

/admin/mail-logs。自動で送られるメールの結果が残ります。「失敗」が出ている間、その相手には自動返信が届いていません。

種類いつ送られるか
会員登録の完了（本人宛）会員登録が完了したとき
新規入会の通知（管理者宛）同上（社内への連絡）
問い合わせ受付（本人宛）お問い合わせが送信されたとき
問い合わせ着信（管理者宛）同上（社内への連絡）

状態は送信済／失敗／未送信の3つ。失敗の行には理由が出ます。よくある原因は、メール送信サービスの設定が未完了、または送信元ドメインの認証が済んでいないことです。

再送のボタンはありません

原因を直したあと、該当のお客様へは手動でご連絡ください。「送ったつもりで届いていない」を防ぐため、失敗は必ず記録に残る作りにしています。

現在の状態

メール送信サービス（Resend）の設定がまだ済んでいないため、いまはすべての送信が「失敗」として記録されます。送信元にするメールアドレスのドメインが決まりしだい設定します。

管理画面での操作が、お客様側でどう見えるかの対応です。

物件詳細写真、価格、所在地、間取り、物件概要、この物件へのお問い合わせ

リノベーション事例・お客様の声・お知らせは、実際の内容をいただくまで「掲載準備中」と表示しています。作り話は載せていません。原稿と写真をいただければ差し替えます。

8. 覚えておく決まりごと

会員限定物件は「隠して」いません。「渡していません」

会員限定にした物件は、ログインしていない方には価格・所在地・間取り・写真をそもそも送っていません。画面上で見えなくしているだけではないので、ページの中身を調べても出てきません。会員限定物件へのお問い合わせも、ログインしないと進めません。

公開レベルの決まり方

公開レベル未ログインの方に見えるもの会員に見えるもの
一般公開すべてすべて
会員限定物件があること（名称など最小限）すべて

メールを今すぐ止めたいとき

誤った内容で自動返信が飛び続けるような事態のために、作り直さずに止めるスイッチがあります。

  1. データベースで止める（すぐ効きます）Supabase の SystemSetting テーブルで MAIL_SENDING_ENABLED の値を false にします。サイトの作り直しは不要です。
  2. 環境変数で止める（作り直しが要ります）Vercel で MAIL_SENDING_DISABLED=true を設定します。1と2はどちらか一方でも「止める」側なら送信されません。

いまの公開状態

サイトは動いていますが、Vercel の閲覧制限がかかっているため一般の方はまだ見られません。物件の登録と確認が済み、公開してよい状態になった時点で制限を外します。独自ドメイン（○○.jp など）もそのときに設定します。

9. 困ったときは

症状考えられる原因対処
CSVの物件名が文字化けする Excelが保存した文字コードの誤判定 取り込み画面に出る「読み取った文字コード」を確認し、化けたまま実行しない。UTF-8で保存し直す
「取り込みを中止しました」と出る 対象エリア外の市区町村コード、必須列の欠落、画面の件数とサーバーの件数の食い違い 画面のメッセージのとおりに直す。1件も書き込まれていないので、直してやり直せば大丈夫
取り込んだ内容を元に戻したい — 完了画面に出た控え番号（#○○）を添えて開発側へご連絡ください
写真がアップロードできない 画像の保管先（Supabase Storage）の設定が未完了 画面に出る「保管先の接続を確認する」を押すと状態が分かります。設定が要る場合は開発側へ
一部の写真だけ取り込まれない ファイル名の管理番号がデータベースにない 取り込まなかったファイルは理由付きで一覧に出ます。管理番号の綴りを確認
メールが「失敗」ばかり メール送信サービスの設定が未完了、または送信元ドメインが未認証 設定を済ませるまでは、お客様へ手動でご連絡ください
管理画面が開けない そのアカウントが管理者になっていない、またはログインし直していない 1章の手順で role を確認し、ログアウトして入り直す
ログインできなくなった パスワードを5回まちがえた 15分待ってからやり直す
